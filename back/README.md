# Backend

Esta carpeta contiene la futura API y la lógica de negocio del módulo financiero.

La tecnología del backend todavía no está definida. Cuando se seleccione, el
código fuente, configuración y pruebas del servidor se organizarán aquí.

Las credenciales de PostgreSQL deben configurarse únicamente en el backend y
mantenerse fuera del control de versiones.
